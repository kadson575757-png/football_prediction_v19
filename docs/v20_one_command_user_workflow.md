# v2.0 One-Command User Workflow

Use `scripts/run_v20_match.py` with home team, away team, competition, season, and match date.

Network is disabled by default. Use `--cache-only` for offline cache runs, `--mock-data-dir` for fixtures, or `--enable-network` for manual live source smoke.

Outputs include final match report, tip card, model probabilities, missing data report, machine result, and artifact index.
