# v1.9 Release Candidate Scope

v1.9 is a preview / analyst decision system.

It provides local evidence intake, match-pack validation, batch operating dashboards, completion templates, portfolio delta previews, and release-readiness reporting.

Scope limits:
- no bets
- no stakes
- no ROI
- no network calls
- no live results
- no guaranteed prediction
- input data must come from the user
- output is decision support, not a guarantee
