# v2.0.1 Realdata Roadmap

v2.0.1 completes the preview path for real match input without requiring an Odds API key.

The expected flow is fixture search, football-data cache, Understat/xG cache, as-of table/form, as-of xG, optional odds, leakage guard, source quality, model preview and a safe decision class.

`DATA_BLOCKED` is reserved for hard source or leakage problems. Weak but usable coverage should become `NO_BET` or `ANALYST_LEAN`.
