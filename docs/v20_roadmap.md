# v2.0 Roadmap

End goal: accept a real match, resolve safe historical sources, apply as-of/no-leakage rules, build features, run model probabilities, and output MODEL_TIP, ANALYST_LEAN, NO_BET, or DATA_BLOCKED.

Current v2.0 includes mock, cache-only, and live-source-ready adapters, fixture resolution, source quality, no-leakage backtest, one-command runner, and release gate.

Not included: automatic betting, stake sizing, ROI, profit evaluation, paywall/login/captcha bypass, guaranteed predictions, or exact-score betting tips.

Release criteria: tests green, network disabled by default, secrets not written, generated outputs not committed, and safety footer present.
