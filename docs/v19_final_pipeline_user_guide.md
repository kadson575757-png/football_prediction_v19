# v1.9 Final Pipeline User Guide

v1.9 turns local football match evidence into preview-only analysis dashboards, batch decision support, completion templates, and release-candidate readiness reports.

It does not place bets, calculate stakes, track ROI, fetch live results, or make external network calls.

Start modes:
- Single match Excel folder
- Raw evidence folders
- Match pack manifest
- Existing batch config

Open first:
- `final_pipeline_dashboard.md`
- `final_user_guide.md`
- `final_action_plan.md`
- `final_release_readiness_report.md`
- `batch_os/executive_dashboard.md`
- `completion_campaign/master_completion_template.csv`
